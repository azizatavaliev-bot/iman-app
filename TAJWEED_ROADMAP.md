# Tajweed - Доработки (Архив идей)

## Приоритет 1 — Улучшение текущего

### 1. Аудио произношение букв (реальные записи)
- Сейчас: Web Speech API (синтезатор, качество среднее)
- Нужно: MP3 файлы от носителя арабского языка для каждой буквы
- Источник: forvo.com API или записать самим
- Каждая буква: изолированно + с фатхой/касрой/даммой = ~112 файлов

### 2. Анимация написания букв
- SVG-анимация: показывать направление штрихов при написании
- Пользователь видит как буква "рисуется" пошагово
- Библиотека: framer-motion или CSS @keyframes по SVG path

### 3. Интервальное повторение (Spaced Repetition)
- Алгоритм SM-2 (как в Anki) для карточек слов и букв
- Автоматический подбор: показывать чаще то, что забываешь
- Хранить в localStorage: дату следующего повторения для каждого элемента

### 4. Уровни сложности в квизе
- Новичок: только распознавание букв
- Средний: харакат + формы написания
- Продвинутый: правила таджвида + примеры из Корана
- Таймер на ответ (опционально)

## Приоритет 2 — Новые режимы

### 5. "Собери слово" — интерактивная игра
- Дано слово на русском, нужно собрать из арабских букв
- Drag & drop или тап по буквам в правильном порядке
- Начать с коротких слов: بسم, الله, رب

### 6. "Найди пару" — Memory Game
- Карточки: арабская буква ↔ её название/звук
- Переворачивай 2 карточки, ищи пары
- Таймер + рекорды

### 7. Диктант
- Воспроизводится звук буквы/слова
- Пользователь выбирает правильную букву из вариантов
- Тренировка слуха — критично для таджвида

### 8. Чтение по слогам (Нурани Каида)
- Классическая методика: буква + огласовка → слог
- Прогрессия: بَ بِ بُ → بَا بِي بُو → بَبَ بَبِ → слова
- 30 уроков от простого к сложному

## Приоритет 3 — Продвинутое

### 9. Цветной таджвид на тексте Корана
- API: quran.com /api/v4 возвращает tajweed-версию текста (с HTML тегами)
- Каждое правило — свой цвет прямо в тексте аята
- Легенда цветов внизу экрана
- Нажатие на цветной фрагмент → объяснение правила

### 10. Запись голоса и сравнение
- Пользователь читает аят → записываем через MediaRecorder API
- Сравниваем длительность и паузы с эталонным чтецом
- Визуализация волновой формы: твоя vs эталон
- Ограничение: точная проверка произношения требует ML (пока только визуально)

### 11. Ежедневные задания
- "Буква дня" — изучи новую букву
- "Повтори 5 слов из вчерашнего аята"
- "Пройди мини-тест по харакатам"
- Push-уведомления через Telegram бот

### 12. Достижения и бейджи
- "Первые 7 букв" 🏅
- "Все харакаты изучены" ⭐
- "10 дней подряд" 🔥
- "Все правила таджвида" 🎓
- "100 слов выучено" 📚

### 13. Офлайн режим
- Service Worker для кэширования данных алфавита и правил
- Аудио файлы кэшировать при первом прослушивании
- В Telegram Mini App ограничен, но базовый кэш работает

## Технические заметки

- Quran.com API v4: `api.quran.com/api/v4/verses/by_key/{surah}:{ayah}?words=true`
- Tajweed text: `api.quran.com/api/v4/quran/verses/uthmani_tajweed?verse_key={surah}:{ayah}`
- Word audio: `audio.qurancdn.com/wbw/...`
- Arabic font: Amiri (уже подключен в index.css)
- SpeechSynthesis lang="ar" — качество зависит от устройства
