## 2026-08-03 (5) — Фикс: модалки открывались посреди страницы, а не по центру экрана
- **Симптом:** нажимаешь кнопку в верхней части экрана (напр. кольцо саваба) — модалка открывается где-то далеко внизу/вверху, приходится скроллить её искать.
- **Причина:** у корневых блоков страниц стоит `animate-fade-in`, а его keyframes заканчивались на `transform: translateY(0)` с `fill-mode: forwards`. По спецификации CSS **любой** transform ≠ `none` делает элемент *containing block* для потомков с `position: fixed` — из-за чего все модалки внутри страницы позиционировались относительно всего (длинного) документа, а не вьюпорта.
- **Фикс:** конечный кадр изменён на `transform: none` — одна строка вместо переписывания 7 файлов с модалками. Превентивно исправлены все 5 keyframes с `forwards`, оставлявшие transform: `fadeIn`, `slideDown`, `splash-rise`, `splashFadeUp`, `tileIn`, `card-enter`.
- Затрагивает модалки в: Dashboard (саваб-коины, уровни), Quran, DuaWall, NamesGame, AboutApp, ShareCard, WelcomeStories.
